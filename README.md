# CV

这是一个基于 HTML、CSS 和 JavaScript 的模块化个人简历页面。

## 项目说明

- 适合本地直接打开预览
- 适合部署到 GitHub Pages、静态服务器或任意前端托管平台
- 简历内容、样式和渲染逻辑已拆分，便于后续维护

## 项目结构

- `index.html`：页面入口
- `assets/styles/main.css`：页面样式
- `assets/data/resume-data.js`：简历数据
- `assets/scripts/templates.js`：页面模板渲染逻辑
- `assets/scripts/main.js`：页面初始化脚本

## 使用方式

1. 直接用浏览器打开 `index.html`
2. 修改 `assets/data/resume-data.js` 中的内容更新简历信息
3. 修改 `assets/styles/main.css` 调整页面样式

## 备注

- 页面支持打印，可通过浏览器导出 PDF
- 当前仓库已使用 Git 管理，并已配置 SSH 方式推送到 GitHub
